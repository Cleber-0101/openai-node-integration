# 🤖 Integração com a API da OpenAI (Node.js)

Exemplo mínimo de integração com a OpenAI em Node.js: envia um prompt para o modelo `gpt-4o-mini` com uma mensagem de sistema e trata erros da API.

## Stack
Node.js (ESM) · SDK `openai` · dotenv

## Como rodar
```bash
npm install
echo "OPENAI_API_KEY=sua_chave" > .env
node servidor.js
```
